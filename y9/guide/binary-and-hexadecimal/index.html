Bits, nibbles and bytes

A computer stores everything in binary. Binary uses only two digits, 0 and 1. One binary digit is called a bit.

NameBitsHoldsExample

The columns

Each column has a place value. The column on the right is worth 1. Each column is worth double the column on its right.

Byte1286432168421
Nibble8421

The largest value

The largest value has every bit set to 1. In a nibble, 1111 is 8 + 4 + 2 + 1 = 15. In a byte, 11111111 is 255. The number 256 needs 9 bits, so it does not fit in a byte.

Key words

binary
A number system that uses only 0 and 1.
denary
Our normal number system, with the digits 0 to 9.
bit
One binary digit, 0 or 1.
nibble
4 bits. Half a byte.
byte
8 bits. Two nibbles.
place value
What a column is worth: 128, 64, 32, 16, 8, 4, 2 or 1.
2

Binary to denary

Add the columns that have a 1. Ignore the columns that have a 0.

Worked example: 01011010

Column1286432168421
Bit01011010

1. Write the bits under the columns.

2. The 1s are under 64, 16, 8 and 2.

3. Add them: 64 + 16 + 8 + 2 = 90.

Worked example: the nibble 1101

Column8421
Bit1101

The 1s are under 8, 4 and 1. 8 + 4 + 1 = 13.

Odd or even

The 1 column decides. A binary number that ends in 1 is odd. A binary number that ends in 0 is even.

01011010 ends in 0, and 90 is even.

Denary to binary

Go from left to right. For each column, ask: does it fit into what is left? Yes: write 1 and take it away. No: write 0.

Worked example: 37 in 8-bit binary

ColumnWhat is leftDoes it fit?Write
12837No0

3237Yes. 37 − 32 = 51
165No0
85No0
45Yes. 5 − 4 = 11

11Yes. 1 − 1 = 01

Read the Write column from top to bottom: 00100101.

Check: 32 + 4 + 1 = 37. Nothing is left over after the 1 column.

All eight bits

An 8-bit answer has eight digits. Write the 0s at the front. 100101 is not an 8-bit answer. 00100101 is.

A nibble

A nibble uses the columns 8, 4, 2 and 1. For 6: 8 does not fit, so 0. 4 fits, so 1, and 2 is left. 2 fits, so 1, and 0 is left. 1 does not fit, so 0. The answer is 0110.

Something left over

When the answer is right, 0 is left after the 1 column.

If something is left over, there is a mistake. Find the row where a column was written as 1 but did not fit.

Hexadecimal

Hexadecimal, or hex, has sixteen digits: 0 to 9, then A to F. One hex digit stands for one nibble.

Binary to hex: cut the byte in half

1. Cut the byte into two nibbles.

2. Work out each nibble with 8, 4, 2 and 1.

3. Change 10 to 15 into A to F.

4. Write the two hex digits side by side.

Worked example: 01111010

Left nibble 0111: 4 + 2 + 1 = 7. Right nibble 1010: 8 + 2 = 10, which is A. The byte is 7A.

Hex to binary: the same cut, backwards

Each hex digit becomes four bits. Write all four, including the 0s.

Worked example: 3A. 3 is 0011. A is 10, which is 1010. Side by side: 00111010.

Hex to denary

Change the hex to binary. Then add the columns that have a 1.

Worked example: 3A is 00111010. The 1s are under 32, 16, 8 and 2. 32 + 16 + 8 + 2 = 58.

Key words

hexadecimal
A number system with sixteen digits: 0 to 9, then A to F. Also called hex.
hex digit
One digit of hex. It stands for one nibble, 0 to 15.
A to F
The letters for 10 to 15. A is 10 and F is 15.

One byte, two hex digits

A byte is two nibbles, so a byte is always two hex digits.

Colour codes

A colour code is three bytes in hex: red, green, then blue. FF means all of it. 00 means none of it.

#FF8000: all of the red, half of the green, no blue. The colour is orange.

Common mistakes

✗ Leaving out the 0s at the front

37 written as 100101 has six bits, not eight.

✓ 00100101

✗ The 1 column on the left

The column values start from the right, not the left.

✓ 128 64 32 16 8 4 2 1, with 1 on the right

✗ Something left over after the 1 column

A column was written as 1 when it did not fit.

✓ Write 1 only when the column fits into what is left

✗ Two digits for one nibble

1100 is 12, but 12 is not a hex digit. 11001000 is not 128.

✓ 12 is C, so 11001000 is C8

✗ A hex digit with fewer than four bits

3A written as 11 and 1010 gives 111010, which has six bits.

✓ 3 is 0011, so 3A is 00111010

✗ The nibbles the wrong way round

01111010 is not A7.

✓ The left nibble gives the left digit: 7A

✗ The largest byte is 256

There are 256 patterns, but the first one is 0.

✓ The largest byte is 255. 256 needs 9 bits

✗ A to F stand for 1 to 6

Hex uses 0 to 9 first. The letters come after 9.

✓ A is 10, B is 11, C is 12, D is 13, E is 14, F is 15

In the exam

The paper

The exam is on paper. It is 40 minutes long. It has questions on binary and hexadecimal. It also has questions on programming: see the Sequence, variables, input and strings guide.

What the questions ask for

  • an 8-bit binary number in denary
  • a denary number in 8-bit binary
  • a nibble in denary
  • a byte in hex
  • a hex number in 8-bit binary
  • a hex number in denary

Working on paper

Write the column values across the top: 128 64 32 16 8 4 2 1. Write the bits under them. Check every denary to binary answer by adding the columns back up.
