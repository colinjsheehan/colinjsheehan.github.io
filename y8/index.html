Lessons

Revisit 1: position and headingPredict where the turtle ends up and which way it faces, and use forward, right and left in the right order. Revisit 2: variablesStore a value in a variable, use it by name, and change one line to change every place it is used. Revisit 3: the for loopUse a for loop to repeat lines a set number of times, and work out the turn for a regular shape. Revisit 4: conditionsUse if, elif and else to choose one path, and test the value on the edge. Revisit 5: ask the userAsk the user a question, turn the answer into a number with int(), and choose what to do with a menu. Revisit 6: making it insistUse a while loop to refuse a value outside the range and ask again until a sensible one is typed. Revisit 7: functionsDefine a function with parameters, call it with values in the right order, and call it with a value the user typed. Revisit 8: the polygon programPut input, validation, selection and a function together in one program, and test it at the edges.
