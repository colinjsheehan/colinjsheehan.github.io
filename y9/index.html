Lessons

Revisit 1: position and headingPredict where the turtle ends up and which way it faces, and use forward, right and left in the right order. Revisit 2: variablesStore a value in a variable, use it by name, and change one line to change every place it is used. Revisit 3: the for loopUse a for loop to repeat lines a set number of times, and work out the turn for a regular shape. Revisit 4: the while loopUse a while loop that repeats while a condition is True, and change a variable inside it so the loop stops. Revisit 5: input and validationTurn typed text into a number with int(), and use a while loop to refuse a value until a sensible one is typed. Revisit 6: counting charactersFind the length of a string, get one character by its index, and take the first few characters with a slice. Revisit 7: DIV and MODUse // for whole boxes and % for what is left over, and work out how many boxes an order needs. Revisit 8: one loop, many shapesUse a for loop to draw the same shape in several places, going through a list of positions. Arrays: one name, many valuesStore values in a list, get one out by its index, change one, and go through them all with a loop. Arrays 2: total, fastest and countUse one loop over a list to find a total, an average, the smallest value and how many values meet a condition.
