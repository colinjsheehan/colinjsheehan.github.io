Sequence: position and heading

A program runs one line at a time, from the top. This order is called sequence. The turtle has a position (where it is) and a heading (which way it faces).

The turtle starts in the middle of the screen. It starts facing right.

CommandWhat it does
forward(100)Moves 100 steps the way the turtle faces. It draws a line.
right(90)Turns a quarter turn clockwise. The turtle does not move.
left(90)Turns a quarter turn anticlockwise. The turtle does not move.
penup()Lifts the pen. The turtle moves without drawing.
pendown()Puts the pen down. The turtle draws again.

Worked example: one line at a time

from turtle import *

forward(80)
right(90)
forward(80)
right(90)
LineWhat the turtle doesFacing after the line
forward(80)Moves 80 and draws a lineright

right(90)Turns clockwiseleft

The program draws two sides of a square. The turtle ends facing left.

A square

A square has 4 sides and 4 corners. The turtle turns 90 degrees at each corner. Every turn goes the same way: all right, or all left. 4 × 90 = 360, which is one full turn.

Key words

sequence
The lines of a program run in order, from the top.
position
Where the turtle is.
heading
Which way the turtle faces.
clockwise
The way the hands of a clock turn. right() turns this way.
anticlockwise
The other way. left() turns this way.
degrees
The size of a turn. A full turn is 360 degrees.

Turning does not move

right() and left() change the heading only. The position stays the same. Only forward() and back() move the turtle.

2

Variables

A variable stores a value. Every variable has a name. The = sign stores a value in a variable. This is called assignment.

from turtle import *

side = 60

forward(side)
right(90)
forward(side)
right(90)
forward(side)
right(90)
forward(side)

The side length is stored once, in the variable side. Every forward line uses the name side. To make the square bigger, change one line: side = 60.

Without the variable, the number is typed in four places. Then four lines must change.

One value at a time

lives = 3
lives = 5
print(lives)

The program prints 5. A variable holds one value at a time. The second line replaces 3 with 5. The last value stored is the one that is used.

The name must match exactly

score = 10
print(Score)

The program stops with an error:

NameError: name 'Score' is not defined

The variable is score, with a small s. Score is a different name. Python has no variable called Score. A NameError means Python does not know a name.

No quotation marks

A variable name is written without quotation marks. fillcolor(roof_colour) uses the value in the variable. fillcolor("roof_colour") uses the text roof_colour, which is not a colour.

Key words

variable
Stores a value. It has a name, such as side.
value
What is stored, such as 60 or "blue".
assignment
Putting a value in a variable with =.
NameError
The error when Python does not know a name.

Spelling counts

colour and color are two different names. score and Score are two different names.

3

Input

input() shows a question and waits. The user types an answer and presses Enter. input() gives back what the user typed.

name = input("What is your name? ")

print("Hello", name)

The value in name comes from the user.

input() always gives text

Text is also called a string. A number that the user types is still text.

number = input("Type a number: ")

print(number + number)

The user types 6. The program prints 66. The value in number is the text "6". The + sign joins two pieces of text, so "6" and "6" make "66".

int() turns text into a whole number

number = int(input("Type a number: "))

print(number + number)

The user types 6. The program prints 12. int() turns the text "6" into the whole number 6, so the + sign adds.

PythonResultWhy
"6" + "6"66Two strings: + joins them.
6 + 612Two integers: + adds them.
"6" + 6TypeErrorPython cannot join text and a number.

Key words

input
What the user types.
string
Text: letters, digits, spaces and symbols, in quotation marks.
integer
A whole number, such as 13.
int()
Turns text such as "13" into the whole number 13.

Read it inside out

int(input("Type a number: ")) runs input() first. Then int() turns the answer into a whole number.

Strings

A string is text. Each letter, digit, space or symbol in it is one character. Python counts the characters from 0, not from 1.

Index0123456
CharacterRainbow
word = "Rainbow"

print(len(word))
print(word[0])
print(word[3])
print(word[0:4])
LinePrintsWhy
print(len(word))7Rainbow has 7 characters.
print(word[0])RIndex 0 is the first character.
print(word[3])nIndex 3 is the fourth character.
print(word[0:4])RainIndex 0, 1, 2 and 3. The slice stops before 4.

Slices

word[0:4] is a slice. It gives the characters from index 0 up to index 3. A slice stops before the second number. word[4:7] gives bow.

The last index

Rainbow has 7 characters, so the last index is 6. word[7] is past the end. The program stops with an error:

IndexError: string index out of range

Joining strings

The + sign joins two strings. "3" + "4" gives 34. With numbers, 3 + 4 gives 7.

Key words

character
One letter, digit, space or symbol.
len()
Gives the number of characters in a string.
index
The number of a character's place. The first index is 0.
slice
Part of a string, such as word[0:4].
IndexError
The error when an index is past the end of the string.

One less than the length

The last index is always one less than the length. Rainbow: length 7, last index 6.

Common mistakes

✗ right(90) turns the turtle to face up

right() turns clockwise. From facing right, a clockwise quarter turn points down.

✓ Facing right, then right(90): facing down

✗ A square with one turn the other way

Three right turns and one left turn do not make a square.

✓ Every turn in a square goes the same way

✗ The first value stays in the variable

lives = 3 then lives = 5. The 3 is replaced.

✓ The last value stored is used: 5

✗ A name spelt two ways

score is stored, then Score is used.

✓ The name must match exactly. If not: NameError

✗ input() gives a number

The user types 6. number + number does not give 12.

✓ input() gives text: "6" + "6" is 66. Use int() to get 12

✗ The first character is at index 1

word[1] of Rainbow is not R.

✓ The first index is 0. word[1] is a

✗ A slice includes the second number

word[0:4] is not Rainb.

✓ The slice stops before 4: Rain

✗ The last index is the length

Rainbow has 7 characters, but word[7] does not exist.

✓ The last index is 6. word[7] gives an IndexError

In the exam

The paper

The exam is on paper. It is 40 minutes long. Every program on it is in Python.

It has questions on sequence, variables, input and strings. It also has questions on binary and hexadecimal: see the Binary and hexadecimal guide.

What the questions ask for

  • what a program prints
  • which way the turtle faces at the end
  • the shape a program draws
  • the wrong line in a program, and what it should be
  • the type of error: NameError or IndexError
  • the word that fills a gap in a line
  • why a program gives its result

Working on paper

Read a program one line at a time, from the top. Write down the heading after every turn. Write down the value of a variable each time it changes.
