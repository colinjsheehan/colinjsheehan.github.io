Lessons

1  Position and headingPredict where the turtle ends up and which way it faces, and use forward, right and left in the right order. 2  VariablesStore a value in a variable, use it by name, and change one line to change every place it is used. 3  The for loopUse a for loop to repeat lines a set number of times, and work out the turn for a regular shape. 4  ConditionsUse if, elif and else to choose one path, and test the value on the edge. 5  Ask the userAsk the user a question, turn the answer into a number with int(), and choose what to do with a menu. R1  Text or number? input() and int()Say what kind of value input() gives, turn it into a number with int(), and use = to store and == to compare. 6  Making it insistUse a while loop to refuse a value outside the range and ask again until a sensible one is typed. 7  Functions: define and callDefine a function that names a job, call it to carry the job out, and call it several times to reuse the same instructions. 7b  Functions: parameters and argumentsGive a function parameters, call it with arguments in the right order, and pass it a value the user typed and the program checked. 8  The polygon programPut input, validation, selection and a function together in one program, and test it at the edges.
