1

What a class is

A class is a definition. An object is one thing made from that definition. The class is written once and says what every object of that kind holds and what it can do. Each object then keeps its own copy of the values.

Changing one object does not touch the other. That separation is the reason a class is used instead of four loose variables for every picture.

Key words

class
The definition of a kind of object.
object
One instance made from a class.
instantiate
To create an object from a class.
attribute
A value an object holds.
method
A subroutine that belongs to a class.
constructor
The method that runs when an object is created.
encapsulation
Keeping attributes private and reaching them only through methods.
2

The four parts of a class

A Paper 4 class question is built from the same four parts every time, and the question says which of them to write.

Header

names the class

Attributes

what each object holds, with data types

Constructor

sets the starting values

Get and set

read and change an attribute

Cambridge pseudocode writes a class like this. The constructor is a procedure named NEW.

CLASS Pet
    PRIVATE Name : STRING
    PUBLIC PROCEDURE NEW(GivenName : STRING)
        Name ← GivenName
    ENDPROCEDURE
ENDCLASS

Paper 4 is answered in a programming language rather than in pseudocode, so this shape has to be written again in Python. Three of the four parts translate directly. The attribute declarations do not, and section 3 is about why.

Read the question

The question names the parts it wants. Where it says to write the class and its constructor and no other methods, writing the get and set methods as well earns nothing and costs time the rest of the paper needs.

3

Private, and the comment block

Python has no way to declare an attribute. An attribute comes into existence when the constructor assigns to it, there is no data type to state, and privacy is a naming convention rather than a keyword. Cambridge works round all three at once.

Two leading underscores

An attribute named with two leading underscores cannot be reached from outside the class by that name. One underscore, or none, leaves it reachable and does not count as private.

self.__Description   # private
self._Description    # not private
self.Description     # not private

The comment block is the declaration

Because there is nowhere to write the data types, the question tells Python candidates to write the attribute declarations as comments. That block is worth a mark of its own, and the data type has to appear in it.

class Picture:
    #self.__Description string
    #self.__Width integer
    #self.__Height integer
    #self.__FrameColour string

Some mark schemes show the data type as a comment on each assignment line inside the constructor instead of as a block above it. Either form earns the mark. What loses it is writing the names with no types, or leaving the comments out altogether.

Check it is private

Create an object and try to read the attribute by name from outside the class.

AttributeError: 'Picture' object
has no attribute '__Description'

That error is the proof. If the value prints instead, the attribute is not private.

Not every question asks

Some class questions ask for private attributes and some do not. Where the question does not say private, attributes without underscores are correct and can be read directly.

4

Worked example

November 2021 Paper 41 Question 2 defines a class Picture holding a description, a width, a height and a frame colour. The constructor takes all four as parameters and sets them to the private attributes.

In pseudocode

CLASS Picture
    PRIVATE Description : STRING
    PRIVATE Width : INTEGER
    PRIVATE Height : INTEGER
    PRIVATE FrameColour : STRING
    PUBLIC PROCEDURE NEW(DescriptionP : STRING, WidthP : INTEGER,
                         HeightP : INTEGER, FrameColourP : STRING)
        Description ← DescriptionP
        Width ← WidthP
        Height ← HeightP
        FrameColour ← FrameColourP
    ENDPROCEDURE
ENDCLASS

In Python

class Picture:
    #self.__Description string
    #self.__Width integer
    #self.__Height integer
    #self.__FrameColour string

    def __init__(self, DescriptionP, WidthP,
                 HeightP, FrameColourP):
        self.__Description = DescriptionP
        self.__Width = int(WidthP)
        self.__Height = int(HeightP)
        self.__FrameColour = FrameColourP

The P on the end of each parameter name keeps the parameter apart from the attribute it is assigned to. It is a convention rather than a rule, and any clear naming works.

Creating an object and reading it back

MyPicture = Picture("Flowers", 30, 40, "black")
print(MyPicture.GetDescription())
MyPicture.SetDescription("Trees")
print(MyPicture.GetDescription())
Flowers
Trees

The dot says the method belongs to that object. Calling GetDescription() on its own, without an object in front of it, is not a method call and will not run.

Where the five marks go

  • The class header, named correctly.
  • The four attribute declarations, with data types.
  • Those attributes being private.
  • The constructor header, taking four parameters.
  • The four parameters assigned to the four attributes.

The last of these is one mark for all four assignments together, so one parameter sent to the wrong attribute loses it.

5

Get and set methods

A private attribute cannot be reached from outside the class, so every class that hides its attributes needs methods to read them and to change them. A get returns a value. A set changes one and returns nothing.

    def GetDescription(self):
        return self.__Description

    def SetDescription(self, DescriptionP):
        self.__Description = DescriptionP

A get method takes no parameter beyond self. A set method takes exactly one. A get that prints rather than returns earns nothing, because the value never reaches the code that asked for it.

Set methods that validate

A set method often has work to do beyond assigning. Where a question states a limit, the checks belong inside the set method, so every route into the attribute is protected by them.

    def SetYPosition(self, Value):
        self.YPosition = self.YPosition + Value
        if self.YPosition > 10000:
            self.YPosition = 10000
        elif self.YPosition < 0:
            self.YPosition = 0

Note that the value is added to the attribute rather than written over it. The question states which of the two is wanted, and the two are not interchangeable.

Test the boundary

Set the position to 9995 and add 20. Set it to 5 and subtract 20.

10000 0

Testing at the limit is the only way to know the two checks work. A test in the middle of the range passes whether they are there or not.

Pseudocode and Python

Questions state the design in pseudocode and the answer is written in Python. These are the parts that change on the way across.

Cambridge pseudocode
Python
CLASS Picture
class Picture:
The class header.
PRIVATE Width : INTEGER
#self.__Width integer
Python has no declaration, so the comment stands in for it and the data type is written there.
PUBLIC PROCEDURE NEW(…)
def __init__(self, …):
The constructor. In Python it is always named __init__ and always takes self first.
Width ← WidthP
self.__Width = WidthP
Assigning to an attribute. Python needs self in front of the name.
PUBLIC FUNCTION GetWidth() RETURNS INTEGER
def GetWidth(self):
A get method. The return type is not written in Python.
MyPicture ← NEW Picture("Flowers", 30, 40, "black")
MyPicture = Picture("Flowers", 30, 40, "black")
Creating an object. Python has no NEW keyword.
MyPicture.SetDescription("Trees")
MyPicture.SetDescription("Trees")
Calling a method on an object. The same in both.
CLASS Cat INHERITS Pet
class Cat(Pet):
Inheritance. The parent goes in brackets in Python.
SUPER.NEW(GivenName)
super().__init__(GivenName)
Calling the parent constructor.

Common mistakes

✗ No comment block

The class header and the constructor are written, and the attributes appear only inside the constructor.

✓ Write the declarations as comments, with a data type on each.

June 2023 Paper 41 Question 2(a), where the block is one of five marks.

✗ Names with no data types

A block listing the attribute names only does not meet what the mark point asks for.

✓ #self.__MaxSpeed integer

The same question. The words "including data types" are in the mark point.

✗ One underscore, or none

self.ID and self._ID are reachable from outside the class.

✓ self.__ID

Any question that states all attributes must be private.

✗ A parameter sent to the wrong attribute

The program still runs, and the values are in the wrong places. The single mark for the assignments is lost.

✓ Create an object and print every attribute back through its get method.

November 2021 Paper 41 Question 2(a).

✗ Writing methods the question excluded

Where a question asks for the class and its constructor and no other methods, extra methods earn nothing.

✓ Write what is asked for, then move to the next part.

June 2023 Paper 41 Question 2(a) and November 2021 Paper 41 Question 2(a).

✗ A get method that prints

Printing inside the method sends the value to the screen instead of back to the caller.

✓ return self.__Width

November 2021 Paper 41 Question 2(b).

✗ A set method that replaces when it should add

Where the question says the value is added to the current position, assigning the parameter over the attribute is a different operation.

✓ self.YPosition = self.YPosition + Value

November 2023 Paper 41 Question 3(a)(iii).

✗ A class that is never instantiated

A class on its own produces no output, so a fault in it is invisible until an object is made.

✓ Create an object and call a method on it before moving on.

Any question whose later parts ask for a screenshot of output.

8

In the exam

Declare the class and its constructor

November 2021 Paper 41 Question 2(a) and June 2023 Paper 41 Question 2(a) both give five marks for this and no more. The marks are spread across the header, the declarations, privacy, the constructor header and the assignments, so a class with a perfect constructor and no comment block takes four of the five.

The get and set methods follow

November 2021 Paper 41 Question 2(b) gives three marks for four get methods, and Question 2(c) two marks for one set method. November 2023 Paper 41 Question 3(a)(iii) gives four for two set methods, because those two have to limit the value as well as change it.

Then an array of objects

November 2021 Paper 41 Question 2(d) gives one mark for declaring an array of 100 objects of that class. Later parts of the same question read the data for those objects out of a text file, so a class question and a file question are often the same question.

Evidence

Program code is copied into the numbered part of the evidence document, and where a part says to test the program, a screenshot of the output goes in beside it. A class that has never been instantiated produces no output to screenshot, so those marks cannot be earned from code alone.

Check your own class

  • Does the comment block name every attribute with a data type?
  • Two leading underscores on each one?
  • Does the constructor take the right number of parameters?
  • Does each parameter reach the attribute of the same name?
  • Have you created an object and called a method on it?
