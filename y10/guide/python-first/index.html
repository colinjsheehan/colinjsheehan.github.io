Example: a validation loop

Input a number. Keep asking until it is from 1 to 20 inclusive.

1 Solve in Python

number = int(input("Enter a number from 1 to 20: "))
while number < 1 or number > 20:
    number = int(input("Must be from 1 to 20. Enter again: "))
print("Accepted:", number)

2 Test

Type 0, then 21, then 20. The program rejects 0 and 21 and accepts 20.

3 Translate

OUTPUT "Enter a number from 1 to 20"
INPUT Number
WHILE Number < 1 OR Number > 20 DO
    OUTPUT "Must be from 1 to 20. Enter again"
    INPUT Number
ENDWHILE
OUTPUT "Accepted: ", Number

Line by line

Each Python input line becomes two lines: an OUTPUT for the prompt and an INPUT.

The indented block ends with ENDWHILE.

Example: a total and an average

Input 10 numbers. Output the total and the average.

1 Solve in Python

total = 0
for count in range(1, 11):
    number = int(input("Enter a number: "))
    total = total + number
print("Total:", total)
print("Average:", total / 10)

2 Test

Enter 1 to 10. The total is 55 and the average is 5.5.

3 Translate

Total ← 0
FOR Count ← 1 TO 10
    OUTPUT "Enter a number"
    INPUT Number
    Total ← Total + Number
NEXT Count
OUTPUT "Total: ", Total
OUTPUT "Average: ", Total / 10

Line by line

range(1, 11) becomes 1 TO 10.

The total starts at 0 before the loop, in both languages.

Traps

✗ Python left in the answer

==, !=, %, //, int(input()) and a colon at the end of a line are Python.

✓ =, <>, MOD, DIV, INPUT, no colon

✗ The range stop value copied

range(1, 11) written as FOR Count ← 1 TO 11 runs 11 times.

✓ FOR Count ← 1 TO 10

✗ No end to the block

Python ends a block by indenting less. Pseudocode needs the word.

✓ ENDIF, ENDWHILE, NEXT Count, UNTIL ...

✗ A WHILE condition copied into UNTIL

WHILE gives the condition to keep going. UNTIL gives the condition to stop.

✓ WHILE Mark < 0 OR Mark > 100 becomes UNTIL Mark >= 0 AND Mark <= 100
