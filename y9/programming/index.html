Lessons

1  Position and headingPredict where the turtle ends up and which way it faces, and use forward, right and left in the right order. 2  VariablesStore a value in a variable, use it by name, and change one line to change every place it is used. 3  The for loopUse a for loop to repeat lines a set number of times, and work out the turn for a regular shape. 4  The while loopUse a while loop that repeats while a condition is True, and change a variable inside it so the loop stops. R1  Start, condition, changeName the start, condition and change of a while loop, and trace it to find how many times it runs and the value when it stops. 5  Input and validationTurn typed text into a number with int(), and use a while loop to refuse a value until a sensible one is typed. 6  Counting charactersFind the length of a string, get one character by its index, and take the first few characters with a slice. 7  DIV and MODUse // for whole boxes and % for what is left over, and work out how many boxes an order needs. 8  One loop, many shapesUse a for loop to draw the same shape in several places, going through a list of positions. 9  Arrays: one name, many valuesStore values in a list, get one out by its index, change one, and go through them all with a loop. 10  Arrays 2: total, fastest and countUse one loop over a list to find a total, an average, the smallest value and how many values meet a condition.
