Lessons

Variables and assignmentStore a value in a variable, change it, read a value from the user, and read the pseudocode for the same ideas. Sequence: input, calculate, outputRead two numbers, work out a total and display it in the right order, and read the pseudocode for the same program. Selection: if and caseUse a condition to choose what a program does, with if and elif and else, and read the pseudocode IF and CASE for the same choices. Count-controlled loops: forUse a for loop to repeat lines a set number of times, build a running total inside a loop, and read the pseudocode FOR loop. Condition-controlled loops: whileUse a while loop to repeat while a condition is true, change the variable so the loop ends, and read the pseudocode WHILE and REPEAT loops.
