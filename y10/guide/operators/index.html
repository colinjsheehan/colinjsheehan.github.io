Three types of operator

An operator is a symbol or word that does something to values. Cambridge pseudocode has three types, and each gives a different kind of result.

Arithmetic

Calculates · result is a number
+-*/^MODDIV

Relational

Compares · result is TRUE or FALSE
=<<=>>=<>

Logical

Joins conditions · result is TRUE or FALSE
ANDORNOT

^ means "raised to the power of", so 4 ^ 2 is 16. <> means "not equal to". The result of a relational operator is always of data type BOOLEAN.

Order of operations

Multiplication and division are done before addition and subtraction, as in mathematics. Brackets make the order clear: use them in longer expressions.

Answer ← Score * 100 / MaxMark
Answer ← Pi * Radius ^ 2

Key words

operator
A symbol or word that does something to values, such as + or AND.
quotient
The whole number part of a division. 17 DIV 5 is 3.
remainder
What is left over after a division. 17 MOD 5 is 2.
library routine
A routine that is ready to use: MOD, DIV, ROUND, RANDOM.
BOOLEAN
A data type with two values, TRUE and FALSE.
2

DIV and MOD

17 sweets are shared equally between 5 people. Each person gets 3 and 2 are left over. 17 / 5 gives 3.4, which answers neither question. DIV and MOD answer both.

RoutineWhat it returnsExample
DIVThe quotient: the fractional part is discardedDIV(10, 3) returns 3
MODThe remainderMOD(10, 3) returns 1

Papers write these in two ways. Both mean the same thing:

DIV(17, 5)      17 DIV 5      // both return 3
MOD(17, 5)      17 MOD 5      // both return 2

Check every answer

quotient × divisor + remainder = the original number. For 23 and 4: DIV is 5, MOD is 3, and 5 × 4 + 3 = 23.

Worked: 23 and 4

1. 23 / 4 is 5.75.

2. DIV keeps the whole number part: 5.

3. 5 lots of 4 is 20, and 23 − 20 = 3, so MOD is 3.

Smaller first number

DIV(4, 5) is 0, because 5 goes into 4 no whole times.

MOD(4, 5) is 4: all 4 are left over.

Where DIV and MOD are used

These are more than arithmetic. Programs use them to test numbers and to take numbers apart.

UsePseudocode
Is X even?IF MOD(X, 2) = 0
Last digit of a number355 MOD 10 is 5
Remove the last digit355 DIV 10 is 35
Check digitCheckDigit ← MOD(Total, 11)
Hours from minutesHours ← DIV(Minutes, 60)

An even number has a remainder of 0 when it is divided by 2, so MOD(X, 2) = 0 is TRUE for every even number and FALSE for every odd one.

Taking 355 apart

355 MOD 10 → 5 (units)

355 DIV 10 → 35

35 MOD 10 → 5 (tens)

35 DIV 10 → 3 (hundreds)

ROUND and RANDOM

ROUND(<value>, <places>) rounds a value to a number of decimal places. RANDOM() returns a random number from 0 to 1, inclusive.

ROUND(4.56, 1)          // returns 4.6
ROUND(3.14159, 2)       // returns 3.14
Value ← ROUND(RANDOM() * 6, 0)   // a whole number from 0 to 6

Smallest and largest values

Paper 2 questions ask for the smallest and largest values an expression with RANDOM can give. Work the expression out with 0 in place of RANDOM(), then again with 1.

Smallest: 0 * 19 is 0. ROUND(0, 0) is 0. 0 + 1 is 1.
Largest: 1 * 19 is 19. ROUND(19, 0) is 19. 19 + 1 is 20.

The expression is built in three parts: multiply, round to a whole number, then move the start.

Rounding a half

Cambridge ROUND looks at the next digit. 5 or more rounds up; less than 5 rounds down.

ROUND(4.56, 1): the next digit is 6, so 4.6.

ROUND(2.5, 0) is 3.

Relational and logical operators in conditions

Every IF, WHILE and UNTIL contains a condition. Relational operators make the comparison; logical operators join comparisons.

IF Answer < 0 OR Answer > 100
  THEN
    Correct ← FALSE
  ELSE
    Correct ← TRUE
ENDIF

OR is TRUE when either comparison is TRUE, so any answer below 0 or above 100 sets Correct to FALSE.

OperatorThe result is TRUE whenExample
ANDboth conditions are TRUEMark >= 0 AND Mark <= 100
ORat least one condition is TRUEMark < 0 OR Mark > 100
NOTthe condition is FALSENOT Found

Two ways round

A valid mark: Mark >= 0 AND Mark <= 100

An invalid mark: Mark < 0 OR Mark > 100

Turning one into the other swaps AND for OR and flips each comparison. Lesson 9 uses both in validation loops.

Common mistakes

✗ Python symbols in a pseudocode answer

IF X == 5, X != 0, 17 % 5 and 17 // 5 are Python.

✓ IF X = 5, X <> 0, MOD(17, 5), DIV(17, 5)

Code answers on Paper 2 are written in pseudocode, except in the scenario question.

✗ = to assign in pseudocode

Total = Total + Mark is a comparison in pseudocode, not an assignment.

✓ Total ← Total + Mark

✗ DIV rounds

DIV(19, 5) is not 4. 19 / 5 is 3.8, and DIV discards the fraction.

✓ DIV(19, 5) is 3

✗ MOD of a smaller number is 0

5 goes into 4 no whole times, so nothing is used up.

✓ MOD(4, 5) is 4

✗ ^ for power in Python

In Python, 4 ^ 2 gives 6. It is a different operation.

✓ Python power is 4 ** 2. Pseudocode power is 4 ^ 2.

✗ Python's round() matches ROUND

Python rounds a half to the even number: round(2.5) is 2, round(3.5) is 4.

✓ Cambridge ROUND(2.5, 0) is 3: a half rounds up.

✗ RANDOM() gives a whole number

RANDOM() alone gives a number such as 0.37.

✓ Multiply, ROUND to 0 places, then add to move the start.

✗ Working out the value by hand

"Output the average rounded to one decimal place" is answered with the routine, not with a calculated number.

✓ OUTPUT ROUND(Total / Limit, 1)

In the exam

"State the purpose", with an example

Some questions ask for the purpose of MOD and DIV and one example statement for each. Marks go to the purposes and to the examples, so give a full example statement every time.

X ← MOD(10, 3)      Y ← DIV(10, 3)

"Explain the purpose"

Expect two marks for each routine: what it does, then a second point or an example.

Use the routine in the statement

To output an average rounded to one decimal place, put ROUND in the statement with two values in its brackets: ROUND(Total / Limit, 1).

Tick-box questions

One-mark questions name the operator from its description: the remainder (MOD), the quotient with the fractional part discarded (DIV), the result of 4 ^ 2 (16), less than or equal to (<=).
