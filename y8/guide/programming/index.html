Variables and assignment

A variable stores a value. Every variable has a name. The = sign stores a value in a variable. This is called assignment.

speed = 30
hat_colour = "purple"

The first line stores the number 30 in speed. The second line stores the text purple in hat_colour. Text goes in quotation marks. A number does not.

One value at a time

speed = 30
speed = 50
print(speed)

The program prints 50. A variable holds one value at a time. The second line replaces 30 with 50. The last value stored is the one that is used.

Why use a variable

from turtle import *

step = 40

forward(step)
right(90)
forward(step)
right(90)
forward(step)
right(90)
forward(step)

The number 40 is stored once, in step. To change the size, one line changes: step = 40. Without the variable, the number is typed four times, so four lines must change. If one is missed, the four sides no longer match.

What = does

age = int(input("How old are you? "))

Python works out the right side first. Then = stores the result in the variable on the left. Here, = stores the number the user typed in age.

The name must match exactly

level = 2
print(Level)

The program stops with a NameError. The variable is level, with a small l. Level is a different name, and Python has no variable called Level.

Key words

variable
Stores a value. It has a name, such as speed.
value
What is stored, such as 50 or "purple".
assignment
Storing a value in a variable with =.
NameError
The error when Python does not know a name.

Say it

= stores a value in a variable. A new value replaces the old value.

Asking the user

input() shows a question and waits. The user types an answer and presses Enter. input() gives back what the user typed, as text.

input() always gives text

Text is also called a string. A number that the user types is still text.

reply = input("Type a number: ")
print(reply + reply)

The user types 8. The program prints 88. The value in reply is the text "8". The + sign joins two pieces of text, so "8" and "8" make "88".

int() turns text into a whole number

reply = int(input("Type a number: "))
print(reply + reply)

The user types 8. The program prints 16. int() turns the text "8" into the whole number 8, so the + sign adds. int() is needed before a sum, and before comparing the answer with a number.

Text and a number

reply = input("Type a number: ")
print(reply + 2)

The program stops with a TypeError. reply holds text, and 2 is a number. Python cannot add text and a number.

PythonResultWhy
"7" + "3"73Two pieces of text: + joins them.
7 + 310Two numbers: + adds them.
"7" + 3TypeErrorText and a number cannot be added.
int("7") + 310int() turns "7" into 7 first.

Asking for a number: the whole line

age = int(input("How old are you? "))

The line needs input() and int(), with input() inside int(). The question goes in quotation marks.

Key words

input()
Waits for the user to type. Gives back what they typed.
string
Text, in quotation marks, such as "8".
integer
A whole number, such as 8.
int()
Turns text such as "8" into the whole number 8.
TypeError
The error when Python cannot use two types together.

Say it

input() always gives text. int() turns it into a number.

Read it inside out

int(input("How old are you? ")) runs input() first. Then int() turns the answer into a whole number.

Making decisions

An if line asks a question. The answer is True or False. If it is True, the indented lines under the if run. If it is False, the lines under else run.

if temp > 30:
    print("hot")
else:
    print("not hot")
temptemp > 30Prints
31Truehot
30Falsenot hot
29Falsenot hot

30 is not greater than 30, so the else runs.

Comparison symbols

SymbolMeansExample
>greater than30 > 30 is False
>=greater than or equal to30 >= 30 is True
<less than3 < 5 is True
<=less than or equal to5 <= 5 is True
==equal to4 == 4 is True

"18 or more" is written age >= 18. The = in >= includes 18 itself.

One = or two

PythonWhat it does
age = 18One = stores 18 in age.
age == 18Two == compare age with 18. The answer is True or False.

An if line compares, so it needs two: if age == 18:. The line if age = 18: is an error.

The colon and the indent

if age >= 18:
    print("adult")
print("done")

Every if, elif and else line ends with a colon :. The indent decides which lines are inside the if. print("adult") is indented, so it is inside. print("done") is not indented, so it always runs.

and, or

age = 13
height = 130

if age >= 12 and height >= 140:
    print("Ride")

and needs both parts to be True. age >= 12 is True, but height >= 140 is False. The print line does not run.

With or in place of and, the print line runs. or needs only one part to be True.

First partSecond partandor

Key words

condition
A question with the answer True or False, such as temp > 30.
if
Runs its indented lines when the condition is True.
else
Runs its indented lines when the condition is False.
indent
The spaces at the start of a line. They put the line inside the if.
colon
The : at the end of every if, elif and else line.

Say it

The if line asks a question. If the answer is True, the indented lines run.

Tracing decisions

With if, elif and else, Python checks the tests from the top, one at a time. The first test that is True runs. Python skips every test after it. If no test is True, the else runs.

if temp >= 30:
    weather = "hot"
elif temp >= 20:
    weather = "warm"
else:
    weather = "cold"

A trace table

A trace table shows each test for each value. "Not checked" means Python skipped the test, because a test above it was True.

The edges

A program goes wrong most often on the edge between two paths. Here the edges are 29 and 30, and 19 and 20. Test the values on each side of every edge.

The order of the tests

if temp >= 20:
    weather = "warm"
elif temp >= 30:
    weather = "hot"
else:
    weather = "cold"

This program never stores "hot". Every temp of 30 or more is also 20 or more, so the first test catches it. Python skips the elif. Put the biggest test first.

A menu

choice = int(input("Choose 1, 2, 3 or 4: "))
price = 0
if choice == 1:
    price = 3
elif choice == 2:
    price = 4
elif choice == 3:
    price = 5
elif choice == 4:
    price = 2
else:
    print("Choose a number from 1 to 4.")
The user typesPrintsprice afterwards
3nothing5
0Choose a number from 1 to 4.0
5Choose a number from 1 to 4.0

A number that is not on the menu, such as 0 or 5, goes to the else. The else prints a message and stores nothing, so price keeps the value it had before the if: 0.

The menu allows 1 to 4. The edge tests for this menu are the lowest and the highest it allows: 1 and 4.

Key words

elif
Short for else if. A second test, checked only when the tests above it are False.
trace
Follow a program one line at a time and write down each value.
edge (boundary)
The value where the program changes from one path to another.
menu
A list of numbered choices for the user.

Only one path runs

In an if, elif and else, only one path runs. After it, Python goes to the first line after the whole if.

Common mistakes

✗ The first value stays in the variable

speed = 30 then speed = 50. The 30 is replaced.

✓ The last value stored is used: 50

✗ input() gives a number

The user types 8. reply + reply does not give 16.

✓ input() gives text: "8" + "8" is 88. Use int() to get 16

✗ int() is left out of the input line

age = input("How old are you? ") stores text.

✓ age = int(input("How old are you? "))

✗ One = in an if line

if age = 18: is an error. One = stores a value.

✓ Two == compare: if age == 18:

✗ > includes the number itself

temp is 30. temp > 30 is not True.

✓ 30 > 30 is False. 30 >= 30 is True

✗ The colon is missing

if age >= 18 is an error.

✓ Every if, elif and else line ends with a colon: if age >= 18:

✗ and means either part

age is 13 and height is 130. age >= 12 and height >= 140 is not True.

✓ and needs both parts to be True. or needs one

✗ Python checks every test

temp is 35. The elif temp >= 20 is not checked.

✓ The first True test runs. Python skips the rest

✗ The smaller test comes first

if temp >= 20: before elif temp >= 30: means "hot" is never stored.

✓ Put the biggest test first

✗ The else changes the variable

The user types 5. The else prints a message only.

✓ price keeps the value it had before the if: 0

In the exam

The paper

The exam is on paper, with no computer. It is 40 minutes long and has 36 marks. Every program on it is in Python. Most answers are a word, a number or one line of code.

What the questions ask for

  • what is stored in a variable after a program runs
  • one line of code: storing a value, asking for a number, an if line, a print line
  • what a symbol does: =, ==, >, >=
  • what is wrong with a line
  • whether an if with and or or is True

Working on paper

Read a program one line at a time, from the top. Write down the value of a variable each time it changes. For an if, elif and else, write True or False next to each test, and stop at the first True.
